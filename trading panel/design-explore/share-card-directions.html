TradePanel — Design Exploration

Share-card directions (alternative to the existing Calendar export)

Three additional share-image templates for "Trade of the Month" / monthly summary, on top of the existing wide calendar PNG (unchanged, still the default). Each is a real 1:1 square, meant to stand alone as a photo on Instagram/X/Stories — not a screenshot of the app. All three carry the same tiny TradePanel mark + the exact legal disclaimer already used in monthlyCalendarCanvas.ts ("TradePanel is a personal record-keeping tool only and does not constitute investment advice of any kind."). Shown here at 400×400 CSS px for side-by-side review; production export should render at 1080×1080 canvas, same proportions.

01

Minimalist — quote-card

1:1 · single number

Almost entirely negative space. One giant P&L figure carries the whole card, everything else recedes — closer to a meditation-app quote card than a trading dashboard. Best for a single standout trade someone wants to post with zero explanation needed.

02

Statistic — achievement badge

1:1 · full monthly recap

Reads like a sports-app "badge earned" screen: headline result up top, then a 2×2 stat grid (Win Rate, Profit Factor, Trades, Best Trade) below it. Best for the monthly-summary share (not a single trade) — more information-dense, feels like a season stat card rather than a single quote.

Implementation notes for the builder

not built here

All three would follow the exact pattern already established by tradeCardCanvas.ts / monthlyCalendarCanvas.ts: a new renderXCanvas(canvas, data) function per template (or one function with a variant param), colors pulled live via readCssVar() (never hardcoded), same shareOrDownloadCanvas() export path. Suggested production size 1080×1080 (vs. the existing calendar's 1200×1500 and Trade-of-the-Month's 1080×1920 — both taller formats). The user would pick a template via a small selector next to the existing Share button on TradeOfTheMonthCard.tsx (and a monthly-recap equivalent for variants 2/3-summary) — the existing wide calendar export stays the default, these are additive options, per the task brief.

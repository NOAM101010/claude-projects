# TradePanel — תקציר פרויקט להתייעצות

מסמך זה מיועד להדבקה בשיחה עם Claude (claude.ai) כדי לתת לו הקשר מלא על הפרויקט, בלי גישה לקוד עצמו. הוא מתאר מה המוצר, איך הוא בנוי, מה כבר קיים ועובד, ומה עדיין פתוח — כדי שאפשר יהיה להתייעץ איתו על החלטות עסקיות/טכניות/עיצוביות מתוך הבנה אמיתית של המצב.

---

## 1. מה זה TradePanel

**PWA (Progressive Web App) לניהול יומן מסחר אישי** — כלי תיעוד ומעקב אחרי טריידים, לא בוט המלצות/סיגנלים ולא ייעוץ השקעות.

**מודל מכירה**: תשלום חד-פעמי (לא מנוי), דרך קוד גישה ייחודי לכל רכישה:
- **Basic — $9.99**: מרחב עבודה (workspace) אחד.
- **Pro — $19.99**: עד 5 מרחבי עבודה נפרדים לאותו חשבון — כל אחד עם הטריידים והסטטיסטיקות שלו בנפרד (שימושי למי שמערבב כמה סגנונות מסחר, כי אחרת הסטטיסטיקות מתמצעות בין אסטרטגיות שונות).
- **אין הרשמה עם אימייל/סיסמה** — זהות מבוססת JWT מותאם + קוד גישה, לא Supabase Auth רגיל.

**עקרון יסוד שחוזר בכל החלטה בפרויקט**: **לעולם לא לבדות דאטה**. כל מספר שמוצג חייב להיות מבוסס דאטה אמיתית — אין sparklines מזויפים, אין "live" שלא באמת מתעדכן, אין הצגת הפסד כ"הישג".

---

## 2. Stack טכני

- **Frontend**: Vite + React + TypeScript
- **Backend/DB**: Supabase (Postgres + RLS + Edge Functions), פרויקט בשם `tradepanel`
- **נתוני שוק**: Finnhub API (מניות/קריפטו), Frankfurter API (שערי חליפין היסטוריים)
- **תשלומים (מתוכנן)**: Gumroad — קוד ייחודי לכל מכירה
- **אחסון (מתוכנן)**: Cloudflare Pages (נבחר במפורש על פני Vercel — עלות $0/חודש)
- **בדיקות**: Vitest, 253 טסטים ירוקים
- **i18n**: 4 שפות מלאות — עברית (RTL), אנגלית, ספרדית, צרפתית

## 3. ארכיטקטורה מרכזית

### זהות / auth
- אין הרשמה — JWT מותאם (`sub`=account_id) שמונפק ע"י Edge Functions (`demo-start`/`redeem`), לא Supabase Auth. RLS מבודד כל לקוח.
- קוד גישה אחד = חשבון אחד, מוגבל למספר מכשירים (או ללא הגבלה בקודים מיוחדים).
- דרגות: `demo` (הדגמה חינמית, 5 טריידים) → `basic` → `pro`. אכיפה כפולה — גם בקליינט וגם ב-DB triggers.

### מרחבי עבודה (Workspaces)
- כל workspace = פול טריידים נפרד + דשבורד נפרד. Pro מקבל עד 5, Basic מקבל 1.
- שינוי הגדרות שדות (Toggle) ב-workspace **לעולם לא** משנה דאטה שכבר נרשמה בטריידים קיימים.

### מטבע — עיקרון חשוב
- לכל טרייד יש מטבע קבוע שנשמר לצמיתות עם הרישום — **לעולם לא מחושב מחדש**.
- מטבע הבסיס של הדשבורד (תצוגה מצטברת) ניתן לשינוי בכל רגע — משפיע רק על התצוגה, לא על הנתונים הגולמיים. ההמרה מבוססת שער היסטורי ליום הכניסה לטרייד (לא שער עדכני), עם cache ב-DB.

### מגבלות לפי דרגה (tier)
| | Demo | Basic | Pro |
|---|---|---|---|
| תמונות גרף | 1 | 50 | 150 |
| סימבולים ב-Watchlist | 2 | 20 | 50 |
| price alerts | 0 | 10 | 30 |
| מרחבי עבודה | 1 | 1 | 5 |
| Setups מותאמים אישית (טקסט חופשי) | ❌ | ❌ | ✅ |

## 4. המסכים באפליקציה (7 מסכים, כולם עברו redesign מלא)

1. **Home** — שעון שוק בזמן אמת (לפי אזור הזמן של המשתמש), טיקר אינדקסים/קריפטו אמיתי, sector heatmap, כרטיס "stack" מונפש ל-SPY/QQQ/BTC.
2. **Journal → Trades** — טבלת עסקאות (דסקטופ) / כרטיסים (מובייל), חיפוש+סינון, ייבוא/ייצוא Excel/JSON/CSV, קו מגמה אמיתי (entry→exit) לכל עסקה.
3. **Journal → Dashboard** — KPIs (P&L, Win Rate, Profit Factor, Expectancy, Max Drawdown, Total Fees Paid...), heatmap שנתי של P&L יומי, equity curve, פילוח לפי סימבול/יום בשבוע, כרטיסי "Insights" (Streak, Best/Worst Trade, Weekly Recap ל-Pro).
4. **Positions** — פוזיציות פתוחות עם מחיר חי (polling כל ~2 דקות), progress bar לכיוון SL/TP, R-multiple חי.
5. **Calendar** — לוח חודשי עם P&L אמיתי לכל יום, "Trade of the Month", ייצוא כתמונה (PNG) לשיתוף — **מוגבל בכוונה לגובה מסך אחד ללא גלילה** (לצילומי מסך).
6. **Tools** — מחשבון גודל פוזיציה, מחשבון P&L, Watchlist עם price alerts דרך push notifications.
7. **Settings** — שם workspace, שפה, מטבע, הפעלה/כיבוי שדות בטופס, ייצוא/ייבוא דאטה, Push notifications, **Danger Zone** ("Clear Trading Data" עם אישור כפול — לא מחיקת חשבון מלאה).

**שפת עיצוב**: "Cinematic Terminal" — רקע כהה + accent ענברי (`#d99a2b`), serif (Frank Ruhl Libre) לכותרות, monospace (JetBrains Mono) למספרים. Light/Dark theme מלא. Layout רספונסיבי עד 1880px ברזולוציות רחבות.

## 5. סטטוס נוכחי (עדכני)

✅ **המוצר עובד קצה-לקצה ומאומת חי** מול הפרויקט האמיתי ב-Supabase — לא רק קוד, נבדק בדפדפן אמיתי: הוספה/עריכה/מחיקת טריידים, דשבורד סטטיסטיקות, לוח שנה, מחשבונים, Watchlist עם push alerts אמיתיים, ייבוא Excel של יומן חיצוני אמיתי.

✅ **7/7 מסכי ה-redesign** הושלמו, אומתו חי (desktop+mobile, dark+light, RTL), ונדחפו ל-git.

✅ **אבטחה**: מעבר אבטחה מלא בוצע — RLS על כל טבלה, race conditions בקוד המימוש (redeem codes, watchlist limits) תוקנו ואומתו עם exploit tests אמיתיים, security headers מתוכננים לזמן הדיפלוי.

✅ **ביצועים**: code-splitting (xlsx + recharts נטענים on-demand), bundle ראשי ירד ב-~51%.

❌ **עדיין לא באוויר** — רץ רק ב-localhost. הדיפלוי (דומיין + Cloudflare Pages + Gumroad) נדחה בכוונה עד שהמוצר "מרגיש גמור" — לפי בקשת המשתמש.

❌ **לא נבדק על מכשיר אמיתי** (iPhone/Android) — רק Windows desktop עד כה.

1. בדיקה אמיתית על מכשיר נייד (PWA install, Safari/iOS, push אמיתי).

## 7. החלטות קבועות — לא לערער עליהן בלי סיבה טובה

- Supabase (לא Vercel) לדאטה; Cloudflare Pages (לא Vercel) לאחסון — שיקול עלות מפורש (חינם).
- תשלום חד-פעמי, לא מנוי — יתרון תחרותי מכוון.
- P&L של טרייד **לעולם לא מחושב מחדש** לאחר שנקבע.
- כל ה"נעילות" הזמניות (למשל שפה נעולה לאנגלית) הן ב-`src/config/locks.ts`, הפיכות, שום תשתית לא נמחקת — רק מוסתרת.
- כלי מחשבון Kelly Criterion/Risk of Ruin נבנה, נוסה, והוסר לגמרי לפי בקשת המשתמש (לא ברור/לא מובן) — לא לבנות מחדש בלי לשאול שוב.

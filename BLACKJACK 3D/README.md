# GOLDEN ACE

מועדון קזינו תלת-ממדי בדפדפן — לובי שמהלכים בו, שלושה משחקים, פרוגרסיה וטבלת שיאים.

## הפעלה

```bash
npm install
npm run dev
```

פותח ב-http://localhost:5180

## מה יש

- **לובי תלת-ממדי** — הליכה חופשית (WASD + עכבר, לחיצה לתפיסת העכבר). ניגשים לשולחן ולוחצים E.
- **בלאק ג'ק** — 3D בגוף ראשון, פיצול/הכפלה/ביטוח, דילר איטי, כלכלת ציפים.
- **מכונת מזל** — 3 גלגלים, RTP ~93.5%.
- **רולטה** — גלגל אירופי (0-36), לוח הימורים מלא, edge של 2.7%.
- **פרוגרסיה** — רמות + XP, פתיחת שולחנות לפי רמה, הישגים.
- **טבלת שיאים** — מקומית כברירת מחדל, online דרך Supabase (ראה `.env.example`).

## מבנה

- `src/three/` — לבני R3F משותפות
- `src/lobby/` — הלובי ההליכתי
- `src/games/{blackjack,slots,roulette}/` — המשחקים (engine טהור + view)
- `src/progression/` — רמות, XP, הישגים
- `src/services/` — טבלת שיאים (local + Supabase)

## בדיקות

```bash
npm test        # 141 טסטים — מנועי המשחקים, תשלומים, תנועת לובי

```

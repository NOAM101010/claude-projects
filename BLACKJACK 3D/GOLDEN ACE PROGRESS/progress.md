Regression tests: `tests/{payout,slots-settle,roulette-settle,scratch}.test.ts`. These tests MUST neutralize achievement AND level-up rewards (pre-unlock achievements + park XP at `xpForLevel(90)`) or the "books balanced" assertions break.
- **Toast auto-hide bug pattern (fixed):** never set a toast's hide `setTimeout` in the same effect that calls `setShown` with `shown` in the deps — the re-render clears the timer. Split into a show effect and a hide effect keyed only on `[shown]`. See `ui/{LevelUpToast,AchievementToast,WinCelebration}.tsx`.
- **RTP is tuned + test-locked:** slots ~93.5%, roulette 2.7% edge, scratch ~81%. Don't change payout tables without re-running balance tests.

## אם בכל זאת פתחת את Supabase — איפה מה

הדשבורד: https://supabase.com/dashboard/project/ylhqwzokrfiwobfurkfx

| כפתור בצד שמאל | מה זה |
|---|---|
| **Table Editor** | כל הטבלאות כמו אקסל. `profiles` = כל השחקנים (צ'יפים, רמה, presence...). `app_config` = מספרי הכלכלה. `user_items` = מי מחזיק איזה פריט. `notifications` = הודעות. `bug_reports` = דוחות באג. `friendships` = חברויות. |
| **SQL Editor** | פה מדביקים ומריצים קבצי SQL שקלוד נותן. New query → Paste → Run. |
| **Authentication → Users** | רשימת החשבונות (אימיילים). פה מוחקים משתמש לגמרי אם צריך. |
| **Database → Functions** | כל ה-RPCs (הפונקציות של המשחק). לרוב לא נוגעים ידנית. |
| **Logs** | אם משהו נשבר — פה רואים שגיאות שרת. |

### לשנות ערך ב-app_config בלי הפאנל
Table Editor → `app_config` → לחיצה על התא `value` של השורה → ערוך את ה-JSON → Save.
עדיף פשוט להשתמש בסקשן **⚖️ Economy tuning** בפאנל.

### מפתחות app_config — מה כל אחד עושה
| מפתח | ברירת מחדל | שולט ב... |
|---|---|---|
| `gift_daily_limit` | `50000` | תקרת מתנת צ'יפים ליום לכל שחקן |
| `streak_rewards` | אובייקט לפי יום | בונוס רצף כניסה: `"7":5000` = יום 7 נותן 5,000 |
| `weekly_podium` | `[5000,2500,1000]` | פרסי פודיום שבועי (מקום 1/2/3) |
| `mission_all_done_bonus` | `5000` | בונוס על 3 המשימות היומיות |
| `max_mission_reward` | `20000` | תקרה לתשלום משימה בודדת |
| `referrer_tiers` | `[3000,7000,15000]` | בונוס למזמין על חבר 1/2/3 |
| `baccarat_banker_payout` | `0.95` | תשלום על זכייה בבנקאי בבאקרה. `1` = בלי עמלה (1:1) |

מחקת שורה או שברת ערך? המשחק חוזר אוטומטית לברירת המחדל הקשיחה — כלום לא נשבר.

# ROYAL 21 — מדריך אימות 2 דפדפנים

> **קודם כול: השתק מוזיקה + כל הסאונד בשני הדפדפנים** — הגדרות (⚙️) → כל הסליידרים ל-0.

**URL:** http://localhost:5199/  (מחשב זה)

## הכנה
- **דפדפן A** = יוצר החדר (host). **דפדפן B** = חלון נפרד (עדיף incognito / פרופיל אחר), משתמש שני מחובר. חדרים דורשים חשבון (לא אורח).
- רשום לפני כל בדיקה את יתרת הציפים (💰 למעלה) של כל שחקן.

## שני מסלולי הצטרפות (שונה בין משחקים!)
| משחק | איך B מצטרף |
|---|---|
| רולטה, פוקר, SnG, בלאק-ג'ק נגד חברים | **קוד**: תפריט → לובי → "הצטרף עם קוד" |
| קוינפליפ, היי-קארד, באקרה | **קישור בלבד**: A מעתיק את ה-URL משורת הכתובת ושולח ל-B |
| כולם | חלופה: פאנל חברים → ＋ ליד שם החבר |

## חדר 1 — רולטה
**A:** מסך ראשי → "רולטה" → מודל **"עם חברים"**. קוד למעלה + "העתק קוד".
**B:** לובי → "הצטרף עם קוד".
1. **ציפים:** A מהמר 100 על אדום → "נקה" → 💰 חוזר בדיוק. חזור: 100 → נקה → 100. **חזור גם בדפדפן B (הלא-host — שם היה הבאג).**
2. **סיבוב מלא:** שניהם מהמרים → A "סובב" → אותו מספר זוכה בשני המסכים → תשלום נכון.
3. **סנכרון:** ז'יטון של אחד מופיע אצל השני תוך שנייה.

## חדר 2 — קוינפליפ
**A:** "ערב משחקים" → צור → קוינפליפ (או `/game/coinflip/room/new`).
**B:** A מעתיק URL משורת הכתובת → B מדביק.
1. **ציפים:** A בוחר צד + 100 → "נקה" → 💰 חוזר. פעמיים. חזור בדפדפן B.
2. **סיבוב מלא:** שניהם בוחרים צד + סכום → A "הטל" → אותה תוצאה → זוכה מזוכה.
3. **סנכרון:** הבחירה של אחד נראית אצל השני.

## חדר 3 — היי-קארד
**A:** "ערב משחקים" או `/game/highcard/room/new`.
**B:** קישור ישיר `/game/highcard/room/CODE`.
1. **ציפים:** A אנטה 100 → "נקה" → 💰 חוזר. פעמיים. חזור בדפדפן B.
2. **סיבוב מלא:** שניהם אנטה → קלף לכל אחד → הגבוה מנצח, אותם קלפים בשני המסכים.
3. **סנכרון:** האנטה של כל שחקן נראית אצל השני.

## חדר 4 — פוקר (נגד חברים)
**A:** מסך ראשי → "פוקר" → מודל פרטי → בליינדים → צור.
**B:** לובי → "הצטרף עם קוד".
1. **ציפים:** buy-in יורד. שב → קום → stack חוזר. buy-in → leave → buy-in → אותו ערך, בלי כפילות.
2. **סיבוב מלא:** יד עד showdown/fold. שני המסכים מסכימים על קופה וזוכה.
3. **סנכרון:** קלפי קהילה זהים; stacks מתעדכנים אצל שניהם.
4. **קלפים מוסתרים:** ראה סעיף DevTools למטה.

## חדר 5 — בלאק-ג'ק נגד חברים  ⏸️ (המתן לאישור — תיקון בעבודה)
**A:** לובי → "בלאק-ג'ק" / "דו-קרב" / `/room/new`.
**B:** לובי → "הצטרף עם קוד". A לוחץ "התחל".
1. **ציפים:** A מהמר 100 → "נקה" → 💰 חוזר בדיוק. חזור. **חזור בדפדפן B.**
2. **סיבוב מלא:** שניהם מהמרים + "מוכן" → חלוקה → hit/stand → דילר → הסדרה. אותם קלפי דילר ותוצאה בשני המסכים.
3. **באג עזיבה:** A מהמר, מקבל קלפים → **A לוחץ "חזרה" באמצע היד** → חוזר. בדוק: אין שולחן חופף/כפול; אין staging חדש מעל שולחן ישן; 💰 של A תואם שרת (רענן — לא קופץ ~500).
4. **סנכרון:** "תור של X" נראה אצל השני.
5. **מינורי:** "עוד יד" — לחיצה אחת או שתיים?

## חדר 6 — באקרה
**A:** מסך ראשי → "באקרה" → נכנס ישר.
**B:** קישור ישיר `/game/baccarat/room/CODE`.
1. **ציפים (החדר שלא היה בו מנגנון החזר):** A מניח 100 על "פלייר" → "נקה" → 💰 חוזר בדיוק. פעמיים. חזור בדפדפן B. נסה גם: A ו-B מהמרים בו-זמנית ואז אחד לוחץ נקה — היתרה חוזרת נכון.
2. **סיבוב מלא:** שניהם מהמרים → חלוקה משותפת → הסדרה → תשלומים. "סיבוב חדש" אוטומטי אחרי ~3ש.
3. **סנכרון:** קלפים ותוצאה זהים; הימורים נראים הדדית.

## חדר 7 — Sit & Go
**A:** מסך ראשי → "SnG" → מודל buy-in.
**B:** לובי → "הצטרף עם קוד".
1. **ציפים:** buy-in יורד בהרשמה. הרשמה → יציאה לפני התחלה → 💰 חוזר, בלי כפילויות (המתן ~8ש לפולינג).
2. **סיבוב מלא:** שניהם נרשמים → טורניר → ידיים עד שאחד מפסיד הכל → הזוכה מקבל את הקופה.
3. **קלפים מוסתרים:** ראה DevTools למטה.

## בדיקת קלפים מוסתרים ב-DevTools (פוקר / BJ MP / SnG)
1. F12 → **Network** → סינון **WS** → לחץ על החיבור `realtime/v1/websocket`.
2. **Messages** → מצא הודעה עם `"table":"rooms"` (או חפש `"seats"`).
3. ב-`payload.record.state`:

**פוקר / SnG:**
- `state.seed` = `0`, `state.cursor` = `0`
- `state.seats[<המושב של B>].hole` = `[{"r":"?","s":"?"},{"r":"?","s":"?"}]` — **לא** קלפים אמיתיים
- המושב שלך (A) — `hole` אמיתי. ב-showdown/all-in קלפי היריב נחשפים — מכוון.

**בלאק-ג'ק MP:**
- `state.seed` = `0`, `state.cursor` = `0`
- `state.dealer.cards[1]` = `{"r":"?","s":"?"}` כל עוד `dealer.hidden === true`.

**אם רואים seed/cursor אמיתיים או קלפי יריב אמיתיים = הצנזור לא פעיל (בעיה).**

## בדיקת host handoff (פוקר / BJ MP / SnG / רולטה)
1. שני שחקנים, יד פעילה.
2. **דפדפן A (host) — סגור את הטאב לגמרי.**
3. בדפדפן B, המתן ~20ש: היד ממשיכה / מגיעה להסדרה; B הופך host; אפשר להתחיל יד חדשה מ-B; ציפים תקינים.
4. פתח מחדש את A ונווט לקוד — A מצטרף כשחקן רגיל, בלי שני hosts, בלי שולחן כפול.
5. **מזעור בלבד** (host ממזער במקום לסגור): אחרי כמה דקות ברקע — B **לא** תפס host בטעות (heartbeat שורד throttling).
